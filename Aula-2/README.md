## Descrição dos Arquivos: 
Projeto desenvolvido para demonstrar a criação de uma página web utilizando HTML5, CSS3 e JavaScript, apresentando conceitos de estruturação, estilização e interatividade. Sendo:
- index.html: arquivo principal responsável pela estrutura e pelo conteúdo da página.
- style.css: arquivo responsável pela estilização visual, organização dos elementos e responsividade do site.
- script.js: arquivo responsável pelas funcionalidades e interações com o usuário, como o evento de clique do botão.

## Tecnologias Utilizadas:
- HTML5
- CSS3
- JavaScript
- Estrutura do projeto

## Conteúdos abordados:
1. Estrutura básica HTML5.
2. Cabeçalho da página (header).
3. Menu de navegação (nav).
4. Títulos e parágrafos.
5. Seções de conteúdo (section).
6. Organização do conteúdo principal (main).
7. Rodapé da página (footer).
8. Estilização com CSS3.
9. Cores, fontes e espaçamentos.
10. Flexbox para organização dos elementos.
11. Responsividade com Media Queries.
12. Manipulação de elementos HTML com JavaScript.
13. Eventos de clique (addEventListener).
14. Alteração dinâmica de conteúdo com JavaScript.

## Execução do Projeto:
Para visualizar o projeto, basta baixar ou clonar o repositório, abrir a pasta do projeto e executar o arquivo index.html em um navegador de internet.

## Objetivo:
Aplicar conhecimentos de HTML5, CSS3 e JavaScript por meio da construção de uma página web, demonstrando a separação entre estrutura, apresentação visual e programação.
