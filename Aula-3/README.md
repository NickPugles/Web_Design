# Atividade Didática de HTML5 e CSS3

## Estrutura do Projeto

│
├── index.html
│
├── style.css

## Descrição

Projeto desenvolvido para demonstrar os principais
elementos de estruturação e formatação de páginas HTML5.

## Tecnologias utilizadas

- HTML5
- CSS3

## Estrutura do projeto

- index.html: estrutura da página.
- style.css: estilização dos elementos.
- README.md: documentação do projeto.

## Conteúdos abordados

1. Estrutura básica HTML5.
2. Cabeçalhos e títulos.
3. Menu de navegação.
4. Seções e artigos.
5. Formatação de textos.
6. Estilização inline.
7. Centralização de texto.
8. Alinhamento justificado.
9. Barra lateral.
10. Rodapé.
11. Comentários no código.

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo index.html em um navegador.

## Objetivo

Aplicar os conhecimentos de HTML5 e CSS3 por meio da construção de uma página web didática.
